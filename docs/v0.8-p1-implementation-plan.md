# v0.8 P1 Implementation Plan — Ledger-Backed Cold Start

Status: **implementation plan — all line numbers verified 2026-07-21** against current source.
Design contract: `docs/v0.8-p1-cold-start-design.md` (committed `56a550b`). Where this plan
corrects the design doc's *mechanism* notes (§5 write side, §7 synthetic set, §5 span form),
the observable contract (v2 fields, load behavior, parity) is unchanged and the design doc
gets matching amendments in the implementation commit.

## 1. Corrected write-path model (supersedes design §5 mechanism note)

Design §5 says "write side: `entity_meta` … one function, so both paths get v2 for free".
**Verified wrong as a mechanism**: `entity_meta`/`build_concept` (`storage.rs:403/367`)
consume pre-resolution `ExtractedUnit`s, so they cannot carry `resolved_calls` or any other
cascade-produced state. Corrected model:

- **New** final-projection v2 builders in `storage.rs` (per design §15 file checklist):
  - `build_v2_concepts_all(projection: &ProjectedGraph) -> Vec<ConceptUpsert>`
  - `build_v2_concepts_for_file(projection: &ProjectedGraph, file_path: &str) -> Vec<ConceptUpsert>`
  - Both set `valid_from = now_iso8601()` (`storage.rs:61`), `valid_to = TS_OPEN`
    (`storage.rs:58`, `"9999-12-31T00:00:00.000000Z"`).
- **`analyze_inner`** (`lib.rs:528`): the pre-cascade v1 flush at `lib.rs:741`
  (`upsert_concepts_bulk(&all_concepts)`) is **removed** (concept collection at 707-740
  discarded, `concepts` from `extract_only` at 670 ignored). The v2 flush is inserted
  **after `resolve_all_calls` and before `persist_edges`** (cascade block `lib.rs:746-757`),
  because ledger edges reference concept ids — concepts must be open before edges assert.
- **`update_file`** (`projection_ops.rs:461`): the Phase-3b `persist_entities` call
  (`projection_ops.rs:511`) is **removed**. The scoped v2 flush is inserted **after
  `resolve_calls_scoped` (`projection_ops.rs:532`) and before `persist_edges_scoped`
  (`projection_ops.rs:534`)**.
- Bulk primitive: `CodeGraphStore::upsert_concepts_bulk(&[ConceptUpsert])` (`storage.rs:151`)
  — the only bulk concept API; both flushes use it.
- `entity_meta`/`build_concept`/`upsert_entities` stay untouched for the legacy
  `index_file` path (`projection_ops.rs:408`) and the v1-store upgrade semantics.

## 2. Concept JSON v2 — final schema (builder + parser contract)

Write: new builders (§1). Read: load parser (§4). Round-trip unit tests assert
builder → parser → struct equality for every kind.

Common to all entities:

```text
"meta_version": 2                 // absent in v1 → load hard-error (design §12)
"kind": "module|class|function|import|constant|type_alias"
"name": <String>                  // explicit; title is not safe (import title = "__import__")
"file_path": <String>             // module-id prefix, e.g. "pkg/alpha.py"
"line": u, "exit_line": u, "docstring": String, "decorators": [String]
"content_hash": "<hex u64>"       // entity-specific body/content hash
```

```text
module:
  "language": <Debug string>          // Language::to_json = format!("{:?}", self) → "Python"
  "parse_quality": <Debug string>     // ParseQuality::to_json → "Clean"|"Partial"|"Tainted"|"Deferred"
  "file_version": 1
  "classes"|"functions"|"imports"|"constants"|"type_aliases": [EntityId]  // canonical ORDERED lists
class:
  "grammar_kind": String
  "parent_class": EntityId | null
  "bases": [UnresolvedRef]            // serde: {name, path:[..], line, col}
  "is_type_checking_only": bool
  "fields": [Field]                   // {name, annotation, source, default_value, is_class_var, span, name_span}
function:
  "fn_kind": <serde FunctionKind>     // Free|Method|StaticMethod|ClassMethod|Property|PropertySetter|
                                      // PropertyDeleter|CachedProperty|AbstractMethod|DataclassSynthesized{from_class}
  "parameters": [Parameter]           // {name, annotation, default_value, is_varargs, is_kwargs, is_positional_only, is_keyword_only}
  "parent_class": EntityId | null
  "return_type": Option<String>
  "is_async": bool, "is_generator": bool
  "source": "impl"|"stub"             // SourceType, lowercase (serde rename_all="lowercase")
  "metrics": {cyclomatic, nesting_depth, return_count}
  "signature_hash": "<hex u64>"
  "span": {start, end}, "name_span": {start, end}     // ByteSpan derives as OBJECT (plan deviation from
                                                      // design §5's `[start, end]` notation — doc amended)
  "resolved_calls": [ResolvedCall]    // serde externally tagged:
                                      //   {"Function": id} | {"Constructor": id} |
                                      //   {"Method": {receiver, method}} | {"Builtin": name} |
                                      //   {"External": name} | {"Unresolved": {reason, raw}}
import:
  "raw": String
  "import_kind": {"variant": "ModuleImport|FromImport|RelativeImport|StarImport|Side",
                  "module": String, "alias": String|null, "names": [[name, alias|null]], "level": u}
                                               // hand-written ImportKind::to_json/from_json, compact per variant
  "is_type_only": bool
  "name_span": {start, end}
constant:
  "annotation": Option<String>, "default_value": Option<String>
  "source": "impl"|"stub"
  "span": {start, end}, "name_span": {start, end}
type_alias:
  "target": String
  "source": "impl"|"stub"
  "span": {start, end}, "name_span": {start, end}
```

Not persisted (design §5): `Function.calls` (raw), `Class.effective/resolved_bases/mro/methods`,
`Module.exports/package/star_exports`, `Function.setter_of`, embeddings.

**Serde work in `types.rs`** (all additive derives):

## 4. Load algorithm — `load_snapshot(db_path: &str, root: Option<&str>)`

Replaces the stub at `lib.rs:2000-2001`. New module `graph/cold_start.rs` (design §15)
holds the pure parts; `lib.rs` wraps in `py.allow_threads` and sets globals.

`cold_start.rs`:
```text
pub fn projection_from_state(state: &MaterializedState) -> Result<ProjectedGraph, String>
    // parse every concept content; require "meta_version" == 2 for canonical kinds
    // {module, class, function, import, constant, type_alias} → hard error
    //   "concept <id> predates concept-JSON v2 (no meta_version); re-run coderadar
    //    analyze to upgrade the store (N of M concepts affected)"
    // kind "Field" concepts (v1 leftovers): skip + count (v2 never writes standalone fields)
    // build modules/classes/functions/imports/constants/type_aliases + file_to_modules
    // (file_path → [module.id]); module_by_dotted_name empty (verified never populated)
    // defaults: Module.package=None exports=[] star_exports=None; Class.effective=Plain;
    // Function.setter_of=None calls=vec![]; Import.resolution=Unresolved; embeddings default
    // hashes: u64::from_str_radix, hex — parse failure = hard error naming the concept
pub fn run_load_cascade(projection: &mut ProjectedGraph, cfg: &ImportGraphConfig) -> Result<(), String>
    // EXACT analyze order minus resolve_all_calls (lib.rs:747-751 mirror):
    // resolve_imports → populate_class_methods → compute_all_mro → resolve_class_hierarchy → resolve_overrides
pub fn rebuild_call_indices(projection: &mut ProjectedGraph, links: &[(src, dst, kind)])
    // 1. From every function's restored resolved_calls, mirroring resolve_one_function
    //    (resolve_calls.rs:106-125, applied 358-377):
    //    Function(id)/Constructor(id) → (func_id, id); Method{..} → (func_id, method);
    //    Builtin(n)/External(n) → (func_id, "external::{n}"); Unresolved → nothing.
    //    Both directions, BTreeSet insert.
    // 2. From ledger links: kind in {"CALLS","IMPORTS","EXTENDS","OVERRIDES"} → SKIP
    //    (CALLS covered by resolved_calls; the other three rebuilt by cascade —
    //    persist_edges_scoped writes exactly these 4 structural kinds, persistence.rs:80-168).
    //    Any other kind (framework synthetics) → (src, dst) into both call indices, deduped.
```

`lib.rs` pyfunction (order matters — one `Arc<CodeGraph>` swap, design §6):
1. `CodeGraphStore::open(db_path)` (`storage.rs:98`).
2. `state = store.reconstruct(&now_iso8601())` — canonical
   `YYYY-MM-DDTHH:MM:SS.ffffffZ` (`storage.rs:61`), **never** the magic string `"now"`
   (macrame `timestamp::normalize`, `src/util/timestamp.rs:78`, rejects it).
3. `cold_start::projection_from_state(&state)`.
4. `cold_start::run_load_cascade(&mut proj, &cfg.import_graph)`.
5. `cold_start::rebuild_call_indices(&mut proj, &state.links)`.
6. `graph = CodeGraph::new(cfg).with_store(store.clone())`;
   `graph.commit_projection(proj)`; then override `graph.indexed_at` =
   **db file mtime (unix seconds)** (not the commit's current-time default).
7. Globals: `*GLOBAL_GRAPH.write() = Some(graph)`; `*INDEXED_ROOT.write() = canonicalize(root)`,
   root = arg, else derived from db path (`db.parent().parent().parent()`,
   i.e. `<root>/.coderadar/store/coderadar.db`), else `None` recorded in outcome;
   `*LEDGER_REVISION.lock() = Some(state.seq_anchor)` (new global next to `INDEXED_ROOT`,
   `lib.rs:96`).
8. Outcome dict: `{ modules, classes, functions, imports, constants, type_aliases, files,
   call_edges, revision (i64|None), predates_recorded_history (bool, from state),
   indexed_at, indexed_root, skipped_field_concepts (u32) }`.

`graph_stats` (`lib.rs:1599-1632`): add key `revision` (int or null from `LEDGER_REVISION`).

   + `register_synthetic_edges_bulk` with sample edges (CALLBACK, DEPENDS_ON) → dump D_A.
2. **Leg B**: same analyze + **same** synthetic edges + `update_file` on one fixture file with
   **identical content** → dump D_B. Assert `D_B == D_A` (update_file idempotency).
   (Design §11.1 omits the synthetic edges on leg B; without them `call_edges` counts differ —
   corrected here; doc amended.)
3. **Leg C**: `coderadar.load(db, R)` → dump D_C. Assert `D_C == D_A` byte-for-byte;
   assert outcome `revision` present.
4. **V1 store rejection**: analyze with store, then sqlite3-patch one `concepts` row's
   `content` to strip `meta_version` (verify macrame `concepts` table columns in
   `schema/ddl.rs` first) → `coderadar.load` raises, message names "predates concept-JSON v2"
   + count; CLI leg: fresh-process `_ensure_graph` falls back to analyze, store upgraded,
   subsequent `load` succeeds.
5. **Staleness**: fresh load path taken (assert `graph_stats()["revision"]` set);
   `os.utime` a source file into the future → fresh process re-analyzes
   (`revision` absent); load works again afterwards.
6. **Export surface gone**: `CodeGraph().export_snapshot` absent;
   `coderadar export` → click "No such command" (exit 2).

## 9. Pitfalls

- **Extension rebuild**: `_core` is compiled; every Rust change needs a rebuild before
  Python-side tests mean anything.
- **macrame `concepts` table schema**: the V1-patch test depends on column names — verify
  `schema/ddl.rs` before writing it.
- **`update_file` no-op**: re-extraction must be deterministic; if the extractor is order-
  sensitive the leg-B test will surface it (that's a real bug, fix in extractor).
- **`module_to_dict` membership order** comes from `Module.classes/functions/…` Vecs —
  v2 JSON preserves them in stored order; do NOT sort.
- **Star-export key form** `f"{py_file}::module"` must be byte-identical between
  `analyze` and `load` (same `root` value → same rglob → same keys).
- **`indexed_at`**: only set from db mtime on the load path; `graph_stats` comparison
  excludes it.
- **`graph_stats.revision`** must be null (not a missing key) on analyze legs so the dump
  canonicalization is stable.
