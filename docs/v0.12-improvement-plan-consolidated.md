## P0 — Wrong answers

### 0.1 `as_of`/Snapshot honesty + blob read path (DR-9, DR-25)

**Code truth:** `Snapshot` (`__init__.py:980`) stores ts, never uses it; `query/callers/callees/traverse/explore`
delegate to live graph; `ops.as_of` (`ops.py:792`) `getattr(snapshot,"find",None)` → `None` → all-`None`.
Only `_core.traverse(as_of=)` downstream is real (`lib.rs:2531-2617`); upstream raises honestly.

**Fix (split per A1/A15):**
- (a) Structural honesty — landable on Macrame 0.18: entity lookup via `reconstruct(T)` (recorded time);
  every method without a temporal path (`query`, `callers`, upstream traverse) raises instead of answering
  from the present; `ops.as_of` distinguishes "not in graph at T" vs "temporal lookup unsupported".
  Normalize timestamps to Macrame canonical UTC or reject as `InvalidRequest`; surface
  `predates_recorded_history` distinctly. Signature decision: `CodeGraph.as_of(ts)` lookup form vs
  `snapshot_at` rename — decide, then pin in the parity test.
- (b) Bytes-at-T — waits on §0.6+§1.9+§3.0: `Snapshot` resolves entity-at-T, then file-bytes-at-T via
  `blob_get(extra.coderadar.source_blob)`, then slices stored `ByteSpan`s (see §3.0/A11).

**Done when:** rename-a-function test: `as_of(before)` → old name (+old bytes once (b) lands),
`as_of(after)` → new name (+new bytes); `Snapshot.query` raises; MCP/CLI/`CodeGraph.as_of` agree;
naive/offset/pre-history/retroactive-correction cases pinned. Do not mark green until (a)+(b) both pass.

### 0.2 Clone determinism (DR-12)

`lsh_index.rs:12,26,46`); final sort only size+similarity; `max_groups` cut at `lib.rs:3096`.

**Fix:** total order at every observable boundary before the cut: fingerprints by
`(file, span.start, span.end, entity_id)`; canonical member/instance order; ordered bucket keys +

**Done when:** three runs on a fixture (incl. exact ties, multi hash seeds, `max_groups` truncation)
give byte-identical JSON.

### 1.9 Blob write path: put-on-index (DR-25; blocked on DR-30 policy)

On every `analyze`/`update_file` file write-through:
1. `blob_put(file_bytes)` → digest (64 lowercase hex). Re-put refreshes `put_at` without rewriting.
2. Digest at **`extra.coderadar.source_blob`** on the file's module concept inside that generation's
   assertion (bitemporal versioning + hot reference for the archive scan). Declare whether
   `coderadar.format` stays 1 or advances; never conflate with content `meta_version:2`.
3. Keep xxh3 `content_hash` for staleness; sha256 is only the address. `validate_digest` at the
   persistence boundary (tested; legacy-extra vs new-extra + ledger-reconstruction tests).
4. Caps: 8 MiB blob cap (`Tuning::max_blob_bytes`) vs 1 MiB watcher `max_file_size_bytes` — raising one
   does not silently raise the other; document the pairing. Oversize = skip blob, keep full graph
   coverage, mark body unavailable, emit typed `blob_skipped_oversize`-style count on **every** report
   surface (`analyze`/`reindex`/`update_file`/watcher; `UpdateReport` has no such field today).
   Put bytes **before** asserting their digest; failure-injection between the two must prove idempotent
   retry with no live-digest-to-absent-bytes (orphans only if documented/bounded).

Do not store diffs (dedup makes them pointless; diffs computed on read §3.0).
**Done when:** unchanged-tree reindex writes 0 new blob bytes; one changed file adds exactly one blob;
digest visible in the file concept's `extra` at that generation.

### 1.10 FTS5 keyword search over concept text (DR-34; spike-proven 2026-10-06)

Macrame 0.19 already ships `concepts_fts` (FTS5 over concept `title`+`content`, trigger-maintained,
rebuildable) with public `vector::keyword_search` (bm25, retired-filtered) + `escape_fts5_query`.
CodeRadar's v2 concept JSON (names, docstrings, file paths, member lists) is already indexed — a
find-symbols-mentioning-X surface needs zero storage change. Spike over the self-host store (5,616 live
concepts): natural queries rank correctly sub-2ms (`watcher debounce` → the debounce test + `watch` +
`start_watcher`; `rename function` → `CodeGraph.rename` + `MutationEngine.plan_rename`; docstring word
`service` → the framework resolver modules); hostile input (`cats not dogs`, unbalanced quote) returns
safe empty, never errors or silent exclusion.

1. Rust: pyfunction `search_symbols(query, top_k)` — `with_graph` → store `read_conn` →
   `escape_fts5_query` + `vector::keyword_search` → list of `{id, rank}` (bm25 negative floats pass
   through; hydrate-lazy via existing lookup, left to the caller). Engine path is `macrame::vector::`
   (0.19.0; crate-root re-export is newer). `top_k` default 10, cap 50.
2. Python: `ops.search_symbols(query, top_k=10, graph=None) -> [{id, rank}]`. MCP/CLI binding rides
   step-4 surface work (tool naming belongs to §1.1–1.8 vocabulary) — this item lands the ops contract.
3. Semantics pinned and documented: escaped-by-default (opt-in `raw` flag for power MATCH syntax);
   **live-only** (engine filters `retired`; historical text search is out of scope — FTS indexes current
   rows, the ledger holds the past); underscore-split (`update_file` → `update` AND `file`: useful, never
exact-identifier — documented with example); JSON-key matches self-penalize via IDF (measured rank
   -0.000, no stop-list); empty query → `[]`; storeless graph → the established honest error (class pinned
   at implementation).
4. Foreign/old stores: verify `concepts_fts` presence on the search path; absent → honest error naming
   `rebuild_fts`, never silent empty.

Non-goals: exact-identifier search, searchable history, body search (bodies live in blobs, unindexed —
the split stands), ranking tuning (BM25 as-is), the `HybridSearch` vector arm (needs populated
embeddings; separate item).
**Done when:** Rust test pins top-1 for two spike probes + hostile-input safety + a retired concept
vanishing from results; Python E2E pins `ops.search_symbols` order-determinism (same query twice,
byte-identical) and the `[]`/error edges; latency recorded, gate 1s (DR-33 lesson: catch pathological,
never flake — measured 0.2–3.7ms debug on self-host scale). Bump +0.0.1 per DR-26, named in DR-34.

## P3 — Performance, persistence, retention

### 3.0 Blob read path: `as_of` serves old code (completes §0.1; DR-25)

`Snapshot` entity-at-T via `reconstruct(T)` → bytes-at-T via `blob_get` → slice stored spans.
Separate contracts: **raw-byte path** (exact original bytes/range; explicit API + errors for missing
body / bad digest / bad span; CRLF + non-ASCII byte-equality tests) vs **display path** (decode/format;
existing line-number prefix = presentation). Missing blob (pre-blob generations, pruned archives) =
"content unavailable for T", distinct from "not in graph at T" and "unsupported" — never a silent
present-tense answer. **Acceptance requires the PyO3 round-trip** (Python → `coderadar._core` →
`blob_get`, byte-equality via `Snapshot` + read-at-T); Rust-only green does not close §3.0.

### 3.1 Embeddings Phase 1 (DR-11 carried)

Model id + preprocessing in dedup key; dimension checks with explicit errors; embed-what decision;
remove silent 10k cap. Design Phase-1 keys blob-ready (future small blobs with model id); persistence waits for 0.13.

### 3.2 No unasked full analyzes

Load stale stores; changed-files-only or staleness banner; full walk only for `reindex --full`.

### 3.3 Upstream traversal — decision gated (DR-9 row)

Waits on Macrame in-edges or reverse-edge ledgering. Do not invest until §0.1+§3.0 land and one real
agent trace needs it; bodies-at-T strengthen the case but do not pre-approve it. Record go/no-go with evidence.

### 3.4 Retention + backup (DR-25 + DR-30)

One archival cutoff (generations or days-hot), documented in `.coderadar.toml`/store doc, enforced by the
same session; blobs follow via the reference scan. Backup = **quiesced/atomic hot+cold pair** (+snapshots/
checkpoint as required) — snapshots carry digests, never bytes; a hot-only backup is pointers.
**Done when:** cutoff written down; archive moves unreferenced blobs cold yet `blob_get`-readable; restore
test proves every retained digest resolves to expected bytes (incl. pre-0.19 and post-0.19 cold files).
