## Behavior changes worth knowing

- **Stricter errors, new exit codes.** `traverse --edges bogus` and
  `visualize --format bogus` now error (exit 1) instead of rendering
  something plausible-looking. Scripts that passed garbage and parsed the
  output will now fail loudly — that is the point.
- **`rename` touches import statements.** A rename now also rewrites the
  `from X import <old>` bindings that name the entity, down re-export
  chains. Review diffs accordingly: more files, but the tree stays
  resolvable (rename-back restores byte-identical, verified live).
- **stdout is machine-readable.** All logging goes to stderr at WARNING by
  default; `CODERADAR_DEBUG=1` restores DEBUG. `query --format json` plus
  unfolded piped tables complete the picture.
- **Ledger schema climbs v15 → v19 on open** (macrame rungs; trigger-only,
  no ETL). Forward-only: older CodeRadar/macrame builds cannot open a
  store once v0.9.0 has touched it. Delete `.coderadar/` to rebuild from
  source if you ever need to go back.
- **Env knobs are validated.** Garbage in `CODERADAR_INDEX_HEARTBEAT` /
  `CODERADAR_INDEX_WAIT` falls back with a stderr note instead of crashing
  the server at import; sub-second values clamp to 1 s. Defaults unchanged
  (wait 25 s, heartbeat 5 s).
